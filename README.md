# Spring Boot Dashboard API

A learning project: a REST API built with **Spring Boot** and **PostgreSQL**, meant to become the backend of a simple e-commerce dashboard.

> This repository is built step by step as a way to learn Spring Boot, so the code favors clarity over completeness.

## Features

- CRUD REST API for products
- Health check endpoint
- Persistence with Spring Data JPA / Hibernate on PostgreSQL (tables are generated automatically)

## Tech stack

| Tool | Purpose |
|---|---|
| Java 25 (LTS) | Language and runtime |
| Spring Boot 4.1.1 | Application framework |
| Spring Web | REST controllers |
| Spring Data JPA (Hibernate) | Database access |
| PostgreSQL | Database |
| Maven (wrapper included) | Build and dependency management |

## Prerequisites

- **JDK 25** (LTS)
- **PostgreSQL** running locally on port `5432`
- **Git**

Maven does not need to be installed: the project ships with the Maven wrapper (`mvnw` / `mvnw.cmd`).

## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/Miorena/Spring-boot-dashboard-learning.git
cd Spring-boot-dashboard-learning
```

### 2. Create the database

Connect to PostgreSQL (psql, DBeaver, pgAdmin...) with an admin user and run:

```sql
CREATE USER dev WITH PASSWORD 'dev';
CREATE DATABASE dashboard OWNER dev;
```

### 3. Check the configuration

The database settings live in `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/dashboard
spring.datasource.username=dev
spring.datasource.password=dev
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```

> These credentials are for local development only. Do not reuse them anywhere else.

### 4. Run the application

Linux / macOS:

```bash
./mvnw spring-boot:run
```

Windows (PowerShell):

```powershell
.\mvnw.cmd spring-boot:run
```

The API starts on `http://localhost:8080`. Check that it is running:

```
GET http://localhost:8080/api/health   ->   OK
```

## API reference

| Method | Endpoint | Description | Success status |
|---|---|---|---|
| `GET` | `/api/health` | Health check | `200 OK` |
| `GET` | `/api/products` | List all products | `200 OK` |
| `GET` | `/api/products/{id}` | Get one product | `200 OK` |
| `POST` | `/api/products` | Create a product | `201 Created` |
| `PUT` | `/api/products/{id}` | Update a product | `200 OK` |
| `DELETE` | `/api/products/{id}` | Delete a product | `204 No Content` |

Requesting, updating or deleting an unknown id returns `404 Not Found`.

### Product model

| Field | Type | Notes |
|---|---|---|
| `id` | `Long` | Generated by the database |
| `name` | `String` | |
| `description` | `String` | |
| `price` | `BigDecimal` | |
| `stock` | `int` | |

### Example

Create a product:

```bash
curl -X POST http://localhost:8080/api/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Keyboard","description":"Mechanical keyboard","price":59.90,"stock":12}'
```

Response:

```json
{
  "id": 1,
  "name": "Keyboard",
  "description": "Mechanical keyboard",
  "price": 59.90,
  "stock": 12
}
```

On Windows PowerShell, use `Invoke-RestMethod` instead of `curl`:

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/products `
  -ContentType "application/json" `
  -Body '{"name":"Keyboard","description":"Mechanical keyboard","price":59.90,"stock":12}'
```

## Project structure

```
src/main/java/com/miorena/dashboard
├── DashboardApplication.java     # Application entry point
├── HealthController.java         # GET /api/health
└── product
    ├── Product.java              # JPA entity
    ├── ProductRepository.java    # Data access (Spring Data JPA)
    └── ProductController.java    # REST endpoints for products
```

Request flow:

```
Client -> ProductController -> ProductRepository -> Hibernate -> PostgreSQL
```
